# 00. NPR 技术总览 —— 非真实感渲染的地图与学习路线

> 本文档是「NPR技术文档」系列文档的第 0 篇（总览篇）。本系列按**入门 → 进阶 → 精通**三个层次递进，面向具备基础图形学知识（理解渲染管线、会写基本 Shader）的开发者，以 Unreal Engine 卡通渲染与《原神》渲染方案为典型案例，系统讲解 NPR 核心算法、Shader 实现与工程选型。

## 1. 什么是 NPR

NPR（Non-Photorealistic Rendering，非真实感渲染）是**不以物理真实为目标**的渲染技术总称。它的目标函数不是「模拟光在真实世界的行为」，而是「复现某种艺术媒介的视觉语言」——动画赛璐璐、漫画网点、水彩、铅笔素描、油画、技术插画……

```
        渲染目标光谱
  物理真实 ◀────────────────────────▶ 艺术表达
     │                                      │
   PBR                                  纯风格化 NPR
   (路径追踪/光栅化 PBR)                 (赛璐璐/素描/水彩)
     │                                      │
     └──────────── 混合地带 ────────────────┘
        风格化 PBR（《原神》角色：保留 PBR
        参数接口，替换光照计算方式）
```

### 1.1 一个必须建立的认知：NPR 是「减法和控制」，不是「简化版 PBR」

| 认知 | 错误版本 | 正确版本 |
|------|---------|---------|
| NPR 是什么 | 「画质更低的渲染」 | 把连续物理量**主动离散化/艺术化**，把光照控制权从物理公式交还给美术 |
| 卡通渲染 | 「N·L 加个阈值就完了」 | 阈值只是入口；工业级卡渲 = 着色 + 描边 + 阴影染色 + 高光 + 边缘光 + 资产制作规范的**系统工程** |
| NPR vs PBR | 对立二选一 | 光谱两端；商业项目多在中间（风格化 PBR） |
| NPR 的性能 | 「比 PBR 便宜」 | 单项便宜，但描边多一遍几何、后处理多全屏 pass，**总成本未必低** |

## 5. 术语约定

| 术语 | 本系列约定含义 | 备注 |
|------|--------------|------|
| NPR | 非真实感渲染总称 | 伞形词，先问「哪一类」 |
| 卡通渲染 / 赛璐璐 Cel Shading | 以色阶离散为特征的动画风渲染 | 本系列最主要的分支 |
| Toon Shading | 与 Cel Shading 同义混用 | 业界不区分 |
| Ramp / 渐变贴图 | 把标量（通常是 N·L）映射为颜色的查找纹理 | 第 03 篇专题 |
| Inverted Hull | 背面外扩描边法 | 也叫 Back-face Outline / 法线外扩 |
| 边缘光 Rim Light | 轮廓处的视角相关补光 | 与描边是不同技术，勿混淆 |
| SDF 面部阴影 | 用有向距离场贴图控制面部阴影形状 | 《原神》为代表 |
| 风格化 PBR | 保留 PBR 参数框架、替换光照计算的混合路线 | 第 08 篇详论 |

## 6. 常见误区（先打预防针）

| 误区 | 事实 |
|------|------|
| 「卡通渲染 = 后处理加个滤镜」 | 后处理量化只是最弱的一条路，无法控制 per-材质差异，且与 Bloom/SSR/自发冲冲突（第 05 篇） |
| 「描边就是 Sobel 边缘检测」 | 屏幕空间描边无法感知 per-对象、随分辨率变化；工业主流是 Inverted Hull（第 02 篇） |
| 「NPR 不需要法线贴图」 | 赛璐璐风通常确实弱化法线细节，但《原神》金属/岩石仍用法线；是否使用是风格决策而非技术限制 |
| 「原神是纯 2D 贴图画出来的」 | 原神角色是完整的 3D 实时光照系统，SDF 面部阴影、Ramp、深度边缘光都是逐帧计算的 |
| 「改 UE 源码加个 Toon Shading Model 就完事」 | GBuffer 通道不足、阴影/Lumen 集成、引擎升级维护才是真实成本（第 05 篇） |
| 「NPR 比 PBR 省性能」 | 着色本身省 ALU，但描边翻倍几何量、多 pass 全屏后处理吃带宽，需整体核算（第 08 篇） |
