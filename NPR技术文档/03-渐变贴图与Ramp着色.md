# 03. 渐变贴图与 Ramp 着色 —— 把色阶控制权交给美术

> 本文档是「NPR技术文档」系列文档的第 3 篇（入门篇）。上一篇用手写阈值控制色阶，天花板很低；工业方案用 **Ramp 渐变贴图**——把 N·L 当作纹理坐标去查一张美术手绘的渐变图。本篇讲清一维/二维/多行 Ramp 的原理、实现、采样坑与《原神》式分区昼夜 Ramp。

## 1. 原理：从「公式量化」到「纹理量化」

```
第 01 篇（公式派）              本篇（贴图派）
toon = step(θ, N·L)      ──►   toon = tex2D(_RampTex, float2(H, row)).rgb
                                        ▲
              色阶的形状、颜色、过渡全部画在纹理里
              美术在 PS 里改图 = 改光照，程序员零介入
```

**核心公式**（一维 Ramp）：

```hlsl
float H = dot(N, L) * 0.5 + 0.5;                    // 半兰伯特 [0,1]
float3 shade = tex2D(_RampTex, float2(H, 0.5)).rgb; // U = 光照强度
float3 col = baseColor * shade;                     // Ramp 给出明暗系数（含染色）
```

Ramp 贴图的**物理含义**：横轴 = 受光程度（左暗右亮），像素颜色 = 该受光程度的明暗系数（通常还包含阴影色相偏移）。一张 256×1 的图就定义了整条光照响应曲线。

## 2. 三种 Ramp 形态

### 2.1 一维 Ramp（U = 光照）

```
Ramp 贴图（256×1，示意）
[■■■ 暗部色 ■■■│▓▓ 过渡 ▓▓│░░░ 亮部 ░░░│□ 高光阶 □]
 0.0            0.4        0.6         0.9      1.0
                                        ▲ 硬边界画在图里 → 色阶形状完全可控
```

- 能表达：任意色阶数、任意边界位置、任意软硬、阴影染色（RGB 而非灰度）
- 这是「阈值+阶梯」的严格超集——手写公式能做到的它都能，反之不然

### 2.2 二维 Ramp（U = 光照，V = 第二维度）

V 轴的常见语义（按项目选其一）：

| V 轴语义 | 效果 | 案例 |
|----------|------|------|
| AO / 遮蔽度 | 暗部细节随遮蔽度变化 | 通用 |
| 阴影软硬 | 同一条 Ramp 里画出「软→硬」过渡 | 《军团要塞 2》式 |
| 材质行 | 每行一个材质（皮肤/布料/金属各行） | 多行 Ramp，见 §3 |
| 昼夜 | 上行白天暗部、下行夜晚暗部 | 《原神》，见 §3 |

⚠️ V 轴连续插值时要小心语义串扰（比如材质行间不应平滑过渡 → 行采样要 clamp 到行中心）。

### 2.3 多行分区 Ramp（《原神》式）

社区复现共识：《原神》角色 Ramp 约 10 行——**上五行白天暗部色、下五行夜晚暗部色**，每行对应一类材质分区（由 LightMap 的材质 ID 通道选择行号）。

```hlsl
// 原神式 Ramp 采样骨架（社区复现共识，非官方源码）
float H    = dot(N, L) * 0.5 + 0.5;
float row  = materialID * 0.1 + 0.05;          // 材质 ID → 行中心 V 坐标
float vDay = row;                              // 白天：上半区
float vNight = row + 0.5;                      // 夜晚：下半区
float3 shade = lerp(tex2D(_Ramp, float2(H, vNight)),
                    tex2D(_Ramp, float2(H, vDay)), dayNightFactor);
// ⚠️ ramp 贴图必须关闭 sRGB；行内 U 方向可用线性过滤，行间 V 方向禁止越界
```

效果：同一件铠甲在正午是冷蓝灰阴影、在黄昏自动变成暖紫阴影——**昼夜色调统一由美术在一张图里控**。

## 3. 采样与资产制作坑（本篇重点）

| 坑 | 现象 | 对策 |
|----|------|------|
| **sRGB 没关** | 暗部色阶发灰、阶数对不上 | Ramp 是数据贴图，导入必须关 sRGB |
| 双线性过滤软化硬边界 | 赛璐璐硬边变「毛边渐变」 | 硬边 Ramp 用 Point 采样，或接受软化当柔边界用 |
| U 轴取错 | 暗亮翻转 | 明确约定 U=0 为暗（多数约定），写进美术规范 |
| Mipmap | 远处色阶被平均、行串扰 | Ramp 贴图**禁用 mip** 或限制到 LOD0 |
| 贴图尺寸 | 128×1 色阶颗粒感 | 256×N 起步；N=行数×2（留过渡带） |
| 半兰伯特输入 | 背光面全采样到暗区 | 确认 Ramp 设计输入域是 [0,1] 的 H，不是 [-1,1] 的 N·L |

### 3.1 一个容易混淆的点：Ramp vs 阈值公式不是竞争关系

工业 Shader 通常**两者都用**：Ramp 决定「暗部染什么色、亮部怎么渐」，`smoothstep` 决定「明暗交界在哪、多锐」。即：

```hlsl
float toon  = smoothstep(_Threshold - _Soft, _Threshold + _Soft, H);  // 交界控制
float3 ramp = tex2D(_RampTex, float2(H, row)).rgb;                    // 色阶染色
float3 col  = baseColor * lerp(ramp * _ShadowBoost, 1.0, toon);
```

⚠️ 把两者叠乘而不理清职责，是调参地狱的开端。约定：**阈值/软度管形状，Ramp 管颜色**。

## 4. 与 PBR 查找表的关系（认知校准）

Ramp 本质是一张 **LUT**（查找表）。PBR 也大量使用 LUT（BRDF 积分图、环境 LUT）——技术上同源：

| | PBR LUT | 卡通 Ramp |
|---|---------|-----------|
| 输入 | 物理量（N·V、roughness） | 半兰伯特 H（人为定义） |
| 内容 | 数值积分结果（可推导） | 美术手绘（不可推导） |
| 目标 | 逼近物理正确 | 逼近艺术风格 |
| 谁生成 | 离线计算 | DCC 手绘/PS 曲线 |

记住这张表就不会再说「卡通渲染没有光照模型」——它有，只是模型参数被烘焙成了一张图。

## 5. 效果与适用场景

| Ramp 形态 | 视觉特征 | 适用 |
|-----------|---------|------|
| 一维硬边 Ramp | 经典赛璐璐 | 角色身体/头发 |
| 一维软边 Ramp | 柔和卡通、水彩底 | 场景植被、Q 版 |
| 二维（V=AO） | 暗部层次丰富 | 写实向风格化 |
| 多行分区 | 材质分区 + 昼夜变色 | 开放世界二游（《原神》） |
| X-Toon（2D 全色调查找） | 色调+细节双轴控制 | 风格实验（Barla 2006） |

## 6. 小结

| 要点 | 说明 |
|------|------|
| 本质 | Ramp = 把光照响应曲线烘焙成纹理 LUT，色阶控制权移交美术 |
| 输入域 | 半兰伯特 H∈[0,1]，U=0 为暗（约定俗成，写进规范） |
| 资产纪律 | 关 sRGB、禁 mip、行采样 clamp 到行中心 |
| 职责划分 | 阈值管明暗交界形状，Ramp 管色阶颜色——勿混用 |
| 原神式 | 多行 = 材质分区 × 昼夜，是开放世界卡渲的标准答案之一 |
| 认知 | Ramp 与 PBR 的 BRDF LUT 技术同源，只是内容从积分变成手绘 |
