NPR 技术总览

入门

卡通渲染三大件：着色、描边、Ramp。能独立手写一套最小可用卡渲 Shader。

01 入门 · SHADING

卡通着色原理与实现

  • 核心：N·L 的量化函数 Q——数学一行，艺术一套
  • 技术史：Decaudin 1996 / Gooch 1998 / Lake 2000 / X-Toon 2006
  • 三种量化：硬阈值 / 多阶阶梯 / smoothstep 可调交界
  • 半兰伯特是卡渲暗部分层的隐形地基
  • 阴影染色：暗部是另一个色相，不是亮度衰减
  • 坑：裸 step 锯齿（fwidth 自适应软化）、多光源勿对总光量化
  • 最小可用三阶卡通光照完整 HLSL
02 入门 · OUTLINE

描边技术全解

  • 先分两类边：外轮廓（视角相关）vs 折痕（几何固有）
  • 四大路线横评：Inverted Hull / 屏幕空间检测 / 几何边 / 贴图画线
  • Inverted Hull 是角色描边事实标准
  • 五个工程细节：硬边断裂、屏幕等宽、FOV 补偿、描边颜色、蒙皮同步
  • 法线外扩 ≠ 等宽：锐角处变粗与补偿的 clamp
  • 商业项目常见分层描边组合（角色 Hull + 贴图内线）
03 入门 · RAMP

渐变贴图与 Ramp 着色

  • 本质：把光照响应曲线烘焙成纹理 LUT，控制权移交美术
  • 三种形态：一维 / 二维（V=AO·软硬·材质·昼夜）/ 多行分区
  • 原神式多行 Ramp：材质分区 × 昼夜两行体系
  • 资产纪律：关 sRGB、禁 mip、行采样 clamp 到行中心
  • 职责划分：阈值管交界形状，Ramp 管色阶颜色
  • 认知校准：Ramp 与 PBR 的 BRDF LUT 技术同源

进阶

补齐工业级细节层，落地真实引擎，拆解商业案例。

04 进阶 · RIM & SPEC

边缘光与风格化高光

  • 描边 ≠ 边缘光：一个画线一个补光，分属不同 pass
  • Rim 两流派：视角 Fresnel 式 vs 深度差分式（原神）
  • 深度 rim 完整 HLSL：8 方向圆环采样 + 仅叠加受光面
  • 三类风格化高光：离散 Blob / Kajiya-Kay 发丝双环 / Matcap
  • 卡渲高光哲学：位置形状是美术参数，不受物理约束
  • Matcap 视角绑定 → 只用于小件，忌大面积主材质
05 进阶 · UE5

UE 卡通渲染实战路径

  • 出发点：UE 无内置 Toon Shading Model
  • 三路径横评：后处理量化 / Unlit 手动光照 / 源码 Custom Shading Model
  • 后处理：SceneColor ÷ BaseColor 反解光照，Before Tonemapping
  • 后处理坑清单：0/0 除法、间接光被阶梯化、per-材质失控
  • 改源码真实成本：GBuffer 通道、版本 rebase、Lumen 兼容
  • UE5.1+ 描边首选 Translucent Overlay Materials
  • 按团队规模的决策表（原型 / 二游 / 中大型 / 移动端）
06 进阶 · 案例

原神渲染方案深度剖析

  • 角色四模块：Toon+Ramp / SDF 面部阴影 / LightMap 分区 / 描边+rim
  • SDF 原理：8 角度手绘阴影图合成 FaceLightMap，-0.5F·L+0.5 判定
  • LightMap 四通道语义（R 金属 / G AO / B 高光形状 / A 材质 ID）社区共识
  • LightMap 范式：贴图通道查表替代 Shader 分支
  • 场景侧（GDC 2021 官方）：树球形法线 / 草 VAT / 岩三层笔触 / 云渐变图
  • 方法论：物理计算保下限、手绘预设保上限
  • 资料基调：角色侧=社区逆向共识，场景侧=官方演讲

精通

超越赛璐璐的风格化武器库，以及渲染方案选型的系统判断力。

07 精通 · STYLES

风格化进阶专题

  • 铅笔素描 TAM（Praun 2001）：明度纹理塔 + 线条超集关系
  • 半调网点：明度→面积覆盖率；屏幕空间 vs 物体空间之争
  • ArcSys 手绘流（GGXrd GDC 2015）：逐顶点手工法线 + UV 控线 + 限帧
  • 水彩/油画：Kuwahara 保边平滑家族；时间稳定性是最大坑
  • Matcap 作为全局风格工具：《Gris》式插画项目
  • 从参考图到技术栈的五问选型法
08 精通 · NPR vs PBR

NPR 与 PBR 系统对比

  • 根本差异：目标函数不同（逼近物理 vs 逼近风格参考）
  • 五维对比：光照模型 / 材质表达 / 渲染管线 / 性能开销 / 适用场景
  • 「NPR 更省性能」终审：GPU 省、几何翻倍、人力高一个量级
  • 混合三层级：参数层 / 响应层 / 分区层（原神范式）
  • 前向 + MSAA 友好 → NPR 是移动端/VR 的天然盟友
  • 五问决策框架：真实？媒介？特写？光照动态？引擎能力？

速查

动手前扫一眼，避开流传最广的 NPR 误读。

误区

十二个必须纠正的说法

  • 「卡通渲染 = 后处理加滤镜」→ 后处理是最弱路径，per-材质失控
  • 「描边就是 Sobel 边缘检测」→ 工业主流是 Inverted Hull
  • 「描边和边缘光是一回事」→ 一个画线一个补光，不同 pass
  • 「NPR 不需要法线贴图」→ 用不用是风格决策，非技术限制
  • 「原神是 2D 贴图画出来的」→ 完整 3D 实时光照系统
  • 「SDF 面部阴影是原神独有」→ 已是二游通用技术
  • 「UE 有内置卡通材质」→ 无内置 Toon Shading Model
  • 「改源码加 Shading Model 就完事」→ GBuffer/升级/Lumen 才是成本
  • 「NPR 一定比 PBR 省性能」→ 着色省、几何翻倍、人力更贵
  • 「卡通渲染阴影就是压暗」→ 暗部是另一个色相（RGB Tint）
  • 「Ramp 和阈值公式二选一」→ 工业方案两者叠用，职责分离
  • 「NPR 和 PBR 必须二选一」→ 商业主流是分区混合管线
铁律

六条设计铁律

  • ① 先分边类型（外轮廓/折痕）再选描边技术
  • ② 明暗交界位置归公式管，色阶颜色归 Ramp 管
  • ③ 半兰伯特保暗部信息，是分层的前提
  • ④ 物理计算保下限，手绘预设保上限
  • ⑤ 贴图通道查表替代 Shader 分支（LightMap 范式）
  • ⑥ 越靠近手绘感，成本越从 GPU 转移到美术管线
  • 性能总账 = GPU 成本 + 几何翻倍 + 全屏 pass + 人力
  • 商业答案 = 角色 NPR + 场景风格化 PBR 的分区管线
