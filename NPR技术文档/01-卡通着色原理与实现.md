# 01. 卡通着色原理与实现 —— 把连续光照变成离散色阶

> 本文档是「NPR技术文档」系列文档的第 1 篇（入门篇）。讲清卡通着色（Cel Shading / Toon Shading）的核心算法：从 Lambert 连续光照出发，经阈值量化得到离散色阶，再到半兰伯特、阴影染色等工业必备变体。

## 1. 核心思想：一次「有损压缩」

PBR/经典光照把 `N·L` 当作连续能量分布；卡通着色把它**量化成 2~4 个色阶**，模拟赛璐璐动画中「亮部/暗部」的分层上色。

```
真实光照（连续）              卡通光照（离散）
N·L: 0.0 ──────────► 1.0      N·L: 0.0 ──────────► 1.0
     ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓░                ▓▓▓▓▓▓▓│░░░░░░░
     平滑渐变                        亮部 │ 暗部（硬边界）

光照公式对照：
  Lambert:   C = BaseColor · LightColor · max(0, N·L)
  Cel:       C = BaseColor · LightColor · Q(max(0, N·L))
                                        ▲
                            Q = 量化函数（阶梯/step/ramp）
```

> **事实 vs 语义**：量化函数 Q 是「事实」（纯数学操作，一行 `step`）；选几个色阶、边界放哪、暗部染什么色是「语义」（艺术决策，没有标准答案）。卡通渲染的技术含量 20% 在 Q，80% 在语义层的调参体系。

## 3. 基础实现：三种量化函数

### 3.1 硬阈值（二值赛璐璐）

```hlsl
// 最简卡通着色 —— 亮/暗两阶
float NdotL = dot(normal, lightDir);
float toon  = step(0.0, NdotL);              // 硬边界：N·L > 0 即亮
float3 col  = lerp(shadowColor, litColor, toon) * baseColor;
```

视觉：明暗交界线锐利、黑白分明。适合：《风筝》式极简风、UI 图标。

### 3.2 多阶阶梯（主流）

```hlsl
// 三阶量化：暗部 / 中间调 / 亮部
float NdotL   = dot(normal, lightDir);
float half_   = NdotL * 0.5 + 0.5;           // 先映射到 [0,1]（半兰伯特，见 §4）
float bands   = 3.0;
float toon    = floor(half_ * bands) / (bands - 1.0);  // 0, 0.5, 1
float3 col    = baseColor * lerp(shadowTint, 1.0, toon);
```

⚠️ **坑 1：锯齿**。硬阶梯边界在几何密集处会产生闪烁锯齿。对策：① 用 `smoothstep` 给边界留 1~2% 过渡带；② 依赖 TAA/MSAA；③ 边界处按屏幕空间导数自适应软化：

```hlsl
float w = fwidth(half_) * 2.0;                 // 屏幕空间变化率 → 自适应过渡宽度
float toon = smoothstep(threshold - w, threshold + w, half_);
```

### 3.3 阈值偏移 + 软化（可调明暗交界线）

```hlsl
float toon = smoothstep(_ShadowThreshold - _ShadowSoft,
                        _ShadowThreshold + _ShadowSoft, half_);
// _ShadowThreshold：明暗交界位置（美术调）  _ShadowSoft：交界锐度
```

这一条是工业卡渲的**事实标准形态**——《原神》复现方案、Unity URP 卡通框架里的「Shadow Threshold / Shadow Smooth」都是它。

## 4. 半兰伯特（Half Lambert）：卡渲的隐形地基

Valve 在《半条命 2》中提出：`H = (N·L) * 0.5 + 0.5`，把 [-1,1] 映射到 [0,1]。

| 方案 | 背光面表现 | 卡渲适用性 |
|------|-----------|-----------|
| `max(0, N·L)` | 纯黑死区，丢失形体 | 差：暗部一片死黑不符合赛璐璐审美 |
| Half Lambert | 背光面保留渐变信息 | **好**：量化后暗部仍有 1~2 个色阶，形体立体 |
| 裸 `N·L` 直接量化 | 边界在 0 处，负值全黑 | 同 `max(0,·)` |

```
N·L:      -1.0 ──────── 0 ──────── +1.0
max(0,·):  [     死黑     ][════亮部渐变════]
HalfLamb:  [═══ 暗部渐变(0~0.5) ══╦══ 亮部渐变(0.5~1) ══]
                                  ▲ 明暗交界被推到 N·L=0 附近
```

⚠️ **坑 2**：半兰伯特会压缩暗部对比。若暗部还想分层，需对 H 做幂次调整（`pow(H, k)`，k>1 压暗部）或直接交给 Ramp 贴图（第 03 篇）。

## 5. 阴影染色：暗部不是「更暗」而是「另一个色相」

赛璐璐动画中，阴影是调色出来的，不是亮度减出来的：

| 流派 | 阴影色规律 | 代表作 |
|------|-----------|--------|
| 日式赛璐璐 | 阴影向蓝/紫偏移，饱和度略升 | 多数新番、《原神》 |
| 美式卡通 | 阴影向暖棕偏移 | 《海绵宝宝》式 |
| 技术插画（Gooch） | 亮部暖（黄）、暗部冷（蓝），明度差减小 | CAD 可视化 |

```hlsl
// 阴影染色：暗部 = baseColor × shadowTint（Tint 是完整 RGB，不是灰度）
float3 litColor    = baseColor * lightColor;
float3 shadowColor = baseColor * _ShadowTint * ambient;
float3 col = lerp(shadowColor, litColor, toon);
```

⚠️ **坑 3**：多光源场景下「暗部」= 没受到主光的区域，此时应叠加**环境光/间接光**而非纯黑。UE 后处理路径最容易在这里翻车（整屏量化会把间接光也阶梯化），见第 05 篇。

## 6. 完整最小可用 Shader（前向单方向光）

```hlsl
// ── 最小可用三阶卡通光照（HLSL，前向，单平行光）──
cbuffer ToonParams {
    float3 _LightDir;    float3 _LightColor;
    float3 _ShadowTint;  float  _Threshold;   // 明暗交界位置 [0,1]
    float  _Soft;        float  _Bands;       // 1=二值, 2+=多阶
    float3 _Ambient;
};

float3 ToonShade(float3 N, float3 baseColor)
{
    float H     = dot(N, -_LightDir) * 0.5 + 0.5;   // 半兰伯特
    float w     = fwidth(H) * 2.0;                  // 抗锯齿过渡宽度
    float toon  = smoothstep(_Threshold - w - _Soft,
                             _Threshold + w + _Soft, H);
    if (_Bands > 1.5)                               // 多阶模式
        toon = floor(toon * _Bands) / (_Bands - 1.0);
    float3 shadow = baseColor * _ShadowTint * _Ambient;
    float3 lit    = baseColor * _LightColor;
    return lerp(shadow, lit, toon);
}
// ⚠️ 多光源：应对每盏灯分别算 toon 再加权，直接对总光照量化会丢光源层次
```

## 7. 效果与适用场景

| 变体 | 视觉效果 | 适用场景 |
|------|---------|---------|
| 二值硬阈值 | 海报化、剪影感 | 极简风游戏、图标、过场演出 |
| 三阶阶梯 | 标准新番动画感 | 二次元角色（身体/头发） |
| smoothstep 柔边界 | 柔和赛璐璐（近年主流） | 偏写实的风格化（《破晓传说》） |
| Half Lambert + 染色 | 暗部透气、色彩统一 | 所有需要环境光融合的开放场景 |
| Gooch 冷-暖 | 形体可读性极强、无真实感 | 医学/工业可视化 |

## 8. 小结

| 要点 | 说明 |
|------|------|
| 本质 | 对 N·L 的量化函数 Q；数学一行，艺术一套 |
| 地基 | 半兰伯特把背光面信息保留下来，是暗部分层的前提 |
| 抗锯齿 | 用 `fwidth` 自适应 smoothstep，不要裸 `step` |
| 阴影 | 暗部是**另一个色相**（RGB Tint），不是亮度衰减 |
| 多光源 | 逐光源量化再叠加，勿对总光照量化 |
| 上限 | 阈值+阶梯是手写 Shader 的天花板；工业方案用 Ramp 贴图（下一篇）接管色阶 |
