# 02. 描边技术全解 —— 轮廓线的四大路线与工程细节

> 本文档是「NPR技术文档」系列文档的第 2 篇（入门篇）。描边（Outline）是卡通渲染辨识度最高的元素。本篇系统对比四大描边路线，讲清每条路的原理、代码骨架、代价与坑，并给出选型决策。

## 1. 先分清两类「边」

描边要解决的几何问题有两种，**没有一种技术能同时完美覆盖**：

```
        相机
         ▼
   ┌───────────┐        ┌───────────┐
   │           │        │   褶皱/折痕 │ ← 内轮廓（Feature/Inner Line）
   │   物体     │        │  ╲   ╱    │    几何上：二面角突变
   │            │       │    ▼     │
   └───────────┘        └───────────┘
   ▲                     例：衣褶、鼻梁、下巴阴影线
   外轮廓（Silhouette）
   几何上：N·V ≈ 0 的位置
```

| 边类型 | 几何判据 | 谁擅长 |
|--------|---------|--------|
| 外轮廓 Silhouette | 视角相关，`dot(N,V) ≈ 0` | Inverted Hull、屏幕空间深度差分 |
| 内轮廓/折痕 Crease | 视角无关，二面角 > 阈值 | 几何边预处理、屏幕空间法线差分 |
| 材质边界 | UV/贴图分区 | 贴图内画线、屏幕空间 ID 差分 |

## 2. 路线一：Inverted Hull（背面外扩）—— 工业主流

### 2.1 原理

渲染两遍物体：第一遍正常渲染；第二遍把顶点**沿法线方向外扩**一个固定宽度，**反转剔除方向**（只画背面）——背面比本体大一圈，多出来的一圈就是轮廓线。

```
本体渲染（Cull Back）        描边 pass（Cull Front，顶点外扩）
     ┌────┐                    ┌──────┐
    /      \                  / ┌────┐ \
   │  本体   │                │  │本体 │  │ ← 外扩的背面壳
    \      /                  \ └────┘ /    只露出边缘一圈
     └────┘                    └──────┘
                               背面壳被本体遮住，只剩轮廓
```

### 2.2 代码骨架

```hlsl
// ── 描边 Pass 顶点着色器（关键三行）──
v2f vert(appdata v)
{
    // ① 在观察空间沿法线外扩（等宽描边的关键）
    float3 posVS  = mul(UNITY_MATRIX_MV, v.vertex).xyz;
    float3 nrmVS  = mul((float3x3)UNITY_MATRIX_IT_MV, v.normal);
    nrmVS.z       = 0.01;                       // 压平 Z 方向分量
    posVS        += normalize(nrmVS) * _OutlineWidth * 0.001;

    // ② 宽度按距离衰减，保持屏幕空间等宽
    //    （透视下远处物体自然变细 → 乘深度补偿）
    o.pos = mul(UNITY_MATRIX_P, float4(posVS, 1));
    return o;
}
// 光栅化状态：Cull Front（画背面壳）
```

### 2.3 必须处理的五个工程细节

| 问题 | 现象 | 对策 |
|------|------|------|
| **硬边/法线不连续** | 描边在硬边处断裂、出现裂缝 | 用**平滑法线**：把平均化法线烘焙进顶点色/切线/第二 UV，描边 pass 用它外扩 |
| 屏幕空间不等宽 | 近处粗、远处细（透视） | 外扩量乘视深（或除以 `w`），让宽度在屏幕空间恒定 |
| FOV 变化 | 切镜头时描边粗细跳变 | 外扩量乘 `tan(fov/2)` 归一化 |
| 描边颜色死板 | 纯黑描边在暗部糊成一团 | 采样顶点色/主贴图，描边色 = `texColor × 暗化系数`（《原神》：按材质 ID 分区配色，见第 06 篇） |
| 顶点动画/骨骼 | 描边壳与本体不同步 | 描边 pass 必须跑**同一份**骨骼/GPU Skinning/VAT 逻辑 |

⚠️ **最大坑：法线外扩 ≠ 等宽**。顶点沿法线外扩后，细长锐角处描边会显著变粗（法线方向与视线夹角问题）。可用观察空间外扩（上例）或按 `1/|N·V|` 补偿，但过度补偿会在轮廓处无限放大——需要 clamp。

## 3. 路线二：屏幕空间边缘检测（后处理描边）

### 3.1 原理

在已渲染的 G-Buffer（深度/法线）上做邻域差分，检测不连续处：

```hlsl
// Roberts Cross / Sobel 在深度+法线上
float  dEdge = DepthEdge(uv);     // 相邻像素深度差 → 外轮廓
float  nEdge = NormalEdge(uv);    // 相邻像素法线差 → 折痕/内轮廓
float  edge  = max(dEdge, nEdge);
color = lerp(sceneColor, _OutlineColor, edgeMask);
```

| 信号 | 检测到的边 | 漏检 |
|------|-----------|------|
| 深度差 | 外轮廓、物体间交叠 | 共面折痕（如桌面上的盒子底边） |
| 法线差 | 折痕、硬边 | 平滑轮廓 |
| 深度+法线 | 大部分边 | 仍有漏检，且远处深度精度差 → 需非线性化/距离归一 |

### 3.2 代价与坑

| 项 | 说明 |
|----|------|
| ✅ 优点 | 与几何无关（毛发/粒子也能描）、全屏一致粗细、无需改资产 |
| ⚠️ 分辨率依赖 | 线宽以像素计，4K 与 720p 视觉不同；缩放分辨率下变糊 |
| ⚠️ 无法 per-对象控制 | 想只给角色描边要借助 **Custom Depth / Stencil** 遮罩（UE/Unity 通用手段） |
| ⚠️ 远景噪声 | 远处几何密集 → 全屏杂线；需按深度衰减 edge 强度 |
| ⚠️ 延迟渲染顺手 | 已有 G-Buffer 时几乎免费；前向渲染需额外 DepthNormals pass |

## 4. 路线三：几何边检测（预处理折痕线）

在 DCC/导入阶段离线计算每条边的二面角，超过阈值标记为「折痕边」，运行时以线段（或细四边形条带）直接渲染。

```
离线预处理                         运行时
for each edge:                     收集标记边 → 生成线带 mesh
  if dihedral(edge) > θ:  ──►      每帧随骨骼蒙皮 → 直接 draw 线条
      mark crease
```

- ✅ 折痕位置**完全美术可控**（画哪里就是哪里），粗细可逐边调
- ✅ 视角无关，不随镜头变化闪烁
- ⚠️ 外轮廓仍需其他技术补；资产管线成本高；动画变形后二面角失效（骨骼驱动的折痕需运行时重算或顶点色标记）

## 5. 路线四：贴图内画线（最「笨」也最可控）

美术直接在贴图/顶点色里画线（《罪恶装备 Xrd》的「本村式线」：用 UV 和贴图控制线宽、断线、粗细渐变）。

- ✅ 艺术控制力上限最高：可以画出「手绘断笔」「交叉处加重」
- ⚠️ 纯资产成本，纹理分辨率决定线条质量；特写镜头露馅
- 常作为 Inverted Hull 的**补充**：外轮廓靠 Hull，细节线靠贴图

## 6. 四路线横评与选型

| 维度 | Inverted Hull | 屏幕空间检测 | 几何边 | 贴图画线 |
|------|:---:|:---:|:---:|:---:|
| 外轮廓 | ★★★ | ★★☆ | ✗ | ✗ |
| 内轮廓/折痕 | △（靠平滑法线救） | ★★☆ | ★★★ | ★★★ |
| per-对象/材质控制 | ★★★ | △（需遮罩） | ★★★ | ★★★ |
| 分辨率无关 | ★★★ | ★ | ★★★ | ★★ |
| 额外几何开销 | ×2 顶点 | 无 | 小 | 无 |
| 全屏带宽开销 | 无（增量 pass） | 高（多纹理邻域采样） | 无 | 无 |
| 美术可控性 | 中 | 低 | 高 | 最高 |
| 典型用户 | 《原神》角色、多数二游 | UE 后处理方案、独立游戏 | 硬表面/机甲 | ArcSys 格斗游戏 |

**商业项目常见组合**（分层描边）：

```
角色：Inverted Hull（外轮廓，顶点色控粗细，材质 ID 控颜色）
  + 贴图画线（五官、衣褶等固定内线）
场景：屏幕空间法线差分（可选，给建筑加折痕线）
特效/UI：不描边（Stencil 排除）
```

## 7. 小结

| 要点 | 说明 |
|------|------|
| 两类边 | 外轮廓（视角相关）与折痕（几何固有）需不同技术，先分类再选型 |
| 主流 | Inverted Hull 是角色描边事实标准；屏幕空间检测是零资产成本兜底 |
| 三大工程坑 | 硬边断裂（平滑法线）、屏幕不等宽（深度/FOV 补偿）、描边颜色（贴图色×暗化） |
| 控制维度 | 粗细（顶点色）、颜色（材质 ID/贴图）、有无（Stencil）三个通道缺一不可 |
| 与边缘光区别 | 描边是「画线」，rim light 是「补光」——不同 pass，别混在一起调（第 04 篇） |
