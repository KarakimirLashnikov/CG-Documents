# 常用宏速查大全

> 系列第 **6** 篇，日常开发的**速查手册**。按"我要做什么"分类组织，每张表都可以直接抄。
>
> ⚠️ 宏的确切集合随 UE 5.x 小版本演进。本文列出的是**稳定且高频**的部分；冷门或新增宏请以引擎头文件（`ShaderParameterStruct.h`、`ShaderPermutation.h`、`Platform.ush`、`Common.ush`）为准。

## 1. 参数结构体宏（C++）

### 1.1 骨架

```cpp
BEGIN_SHADER_PARAMETER_STRUCT(StructName, )
    // 成员
END_SHADER_PARAMETER_STRUCT()
```

| 宏 | 作用 |
|----|------|
| `BEGIN_SHADER_PARAMETER_STRUCT(Type, Extra)` | 开始定义参数结构体 |
| `END_SHADER_PARAMETER_STRUCT()` | 结束定义 |
| `SHADER_USE_PARAMETER_STRUCT(ShaderClass, BaseClass)` | 让 shader 类使用内部 `FParameters` |

### 1.2 值类型

| 宏 | HLSL | 备注 |
|----|------|------|
| `SHADER_PARAMETER(Type, Name)` | `Type Name;` | 标量 / 向量 / 矩阵 |
| `SHADER_PARAMETER_ARRAY(Type, Name, Count)` | `Type Name[Count];` | 定长数组 |

**推荐的类型映射**：

| C++ | HLSL | 字节 |
|-----|------|------|
| `uint32` | `uint` | 4 |
| `int32` | `int` | 4 |
| `float` | `float` | 4 |
| `FVector2f` | `float2` | 8 |
| `FVector3f` | `float3` | 12 |
| `FVector4f` | `float4` | 16 |
| `FMatrix44f` | `float4x4` | 64 |
| `FIntPoint` | `int2` | 8 |
| `FUintVector2` / `FIntVector` | `uint2` / `int3` | 8 / 12 |

> ❌ **绝对不要用**：`FVector`、`FVector4`、`FMatrix`、`FLinearColor`（UE5 下是 double，编译报错）。

### 1.3 资源类型

| 宏 | 字段类型 | HLSL |
|----|---------|------|
| `SHADER_PARAMETER_TEXTURE(Type, Name)` | `FRHITexture*` | `Texture2D Name;` |
| `SHADER_PARAMETER_SRV(Type, Name)` | `FRHIShaderResourceView*` | `Type Name;` |
| `SHADER_PARAMETER_UAV(Type, Name)` | `FRHIUnorderedAccessView*` | `Type Name;` |
| `SHADER_PARAMETER_SAMPLER(Type, Name)` | `FRHISamplerState*` | `SamplerState Name;` |

### 1.4 RDG 资源类型（RDG Pass 内首选）

| 宏 | 字段类型 |
|----|---------|
| `SHADER_PARAMETER_RDG_TEXTURE(Type, Name)` | `FRDGTextureRef` |
| `SHADER_PARAMETER_RDG_TEXTURE_SRV(Type, Name)` | `FRDGTextureSRVRef` |
| `SHADER_PARAMETER_RDG_TEXTURE_UAV(Type, Name)` | `FRDGTextureUAVRef` |
| `SHADER_PARAMETER_RDG_BUFFER(Type, Name)` | `FRDGBufferRef` |
| `SHADER_PARAMETER_RDG_BUFFER_SRV(Type, Name)` | `FRDGBufferSRVRef` |
| `SHADER_PARAMETER_RDG_BUFFER_UAV(Type, Name)` | `FRDGBufferUAVRef` |
| `SHADER_PARAMETER_RDG_UNIFORM_BUFFER(Type, Name)` | `TRDGUniformBufferRef<Type>` |

> **规律**：带 `RDG_` 的字段类型是 RDG 句柄（`FRDG*Ref`），不带的是裸 RHI 句柄（`FRHI*`）。RDG 版本能让 RDG 自动推导屏障。

### 1.5 结构体嵌套

| 宏 | 语义 | HLSL 访问 |
|----|------|----------|
| `SHADER_PARAMETER_STRUCT(Type, Name)` | 嵌套子结构 | `Name.Field` |
| `SHADER_PARAMETER_STRUCT_INCLUDE(Type, Name)` | 内联展开（成员平铺进父结构） | `Field` |
| `SHADER_PARAMETER_STRUCT_REF(Type, Name)` | 引用一个**全局 UB** | `Name.Field` |

### 1.6 渲染目标

| 宏 | 说明 |
|----|------|
| `RENDER_TARGET_BINDING_SLOTS()` | 声明 `RenderTargets[0..7]` + DepthStencil，全屏 Pass 必备 |

```cpp
PassParameters->RenderTargets[0] = FRenderTargetBinding(
    OutputTexture, ERenderTargetLoadAction::ENoAction);
PassParameters->RenderTargets.DepthStencil = FDepthStencilBinding(
    DepthTexture, ERenderTargetLoadAction::ELoad, ERenderTargetStoreAction::EStore,
    FExclusiveDepthStencil::DepthWrite_StencilWrite);
```

## 2. 全局 Uniform Buffer 宏

```cpp
// 头文件
BEGIN_GLOBAL_SHADER_PARAMETER_STRUCT(FMyGlobalParams, )
    SHADER_PARAMETER(FMatrix44f, ViewProj)
    SHADER_PARAMETER(FVector4f,  CameraPos)
    SHADER_PARAMETER(float,      Time)
END_GLOBAL_SHADER_PARAMETER_STRUCT()

// .cpp（第二个参数 = HLSL 里的变量名）
IMPLEMENT_GLOBAL_SHADER_PARAMETER_STRUCT(FMyGlobalParams, "MyGlobals");
```

| 宏 | 位置 | 作用 |
|----|------|------|
| `BEGIN_GLOBAL_SHADER_PARAMETER_STRUCT(Type, )` | .h | 定义结构体 |
| `END_GLOBAL_SHADER_PARAMETER_STRUCT()` | .h | 结束 |
| `IMPLEMENT_GLOBAL_SHADER_PARAMETER_STRUCT(Type, "HLSLName")` | **.cpp** | 注册全局 UB 与 HLSL 变量名 |

HLSL 侧**无需声明**，全局可见：

```hlsl
float4 P = mul(float4(WorldPos, 1), MyGlobals.ViewProj);
```

| 创建方式 | 用法 |
|---------|------|
| 立即模式 | `TUniformBufferRef<T>::CreateUniformBufferImmediate(Params, UniformBuffer_SingleFrame)` |
| RDG | `GraphBuilder.CreateUniformBuffer(Params)` → `TRDGUniformBufferRef<T>` |

| `EUniformBufferUsage` | 语义 |
|---------------------|------|
| `UniformBuffer_SingleFrame` | 一帧内有效（最常用） |
| `UniformBuffer_MultiFrame` | 跨帧有效 |
| `UniformBuffer_SingleDraw` | 单次 draw 内有效 |

## 3. Shader 声明与实现宏

| Shader 类型 | 声明 | 实现 |
|------------|------|------|
| `FGlobalShader` | `DECLARE_GLOBAL_SHADER(Class)` | `IMPLEMENT_GLOBAL_SHADER(Class, "path.usf", "Entry", SF_Xxx)` |
| `FMaterialShader` | `DECLARE_SHADER_TYPE(Class, Material)` | `IMPLEMENT_MATERIAL_SHADER_TYPE(, Class, TEXT("path.usf"), TEXT("Entry"), SF_Xxx)` |
| `FMeshMaterialShader` | `DECLARE_SHADER_TYPE(Class, MeshMaterial)` | `IMPLEMENT_MATERIAL_SHADER_TYPE(, Class, TEXT("path.usf"), TEXT("Entry"), SF_Xxx)` |
| 通用 | `DECLARE_SHADER_TYPE(Class, Global)` | `IMPLEMENT_SHADER_TYPE(, Class, TEXT("path.usf"), TEXT("Entry"), SF_Xxx)` |
| **跨模块**（Global） | `DECLARE_EXPORTED_SHADER_TYPE(Class, Global, MODULE_API)` | `IMPLEMENT_EXPORTED_SHADER_TYPE(, Class, TEXT(...), TEXT(...), SF_Xxx, MODULE_API)` |
| **模板化** | 同上 | `IMPLEMENT_SHADER_TYPE(template<>, Class<Arg>, ...)` |

### 3.1 Shader 频率

| 枚举 | 阶段 |
|------|------|
| `SF_Vertex` | 顶点 |
| `SF_Pixel` | 像素 |
| `SF_Geometry` | 几何 |
| `SF_Hull` | 细分控制 |
| `SF_Domain` | 细分求值 |
| `SF_Compute` | 计算 |
| `SF_RayGen` / `SF_RayHitGroup` / `SF_RayMiss` 等 | 光追（按版本可用） |

### 3.2 完整示例

```cpp
// .h
class FMyShader : public FGlobalShader
{
public:
    DECLARE_GLOBAL_SHADER(FMyShader);
    SHADER_USE_PARAMETER_STRUCT(FMyShader, FGlobalShader);

    BEGIN_SHADER_PARAMETER_STRUCT(FParameters, )
        SHADER_PARAMETER(FVector4f, Color)
        RENDER_TARGET_BINDING_SLOTS()
    END_SHADER_PARAMETER_STRUCT()
};

// .cpp
IMPLEMENT_GLOBAL_SHADER(FMyShader,
    "/Plugin/MyPlugin/Private/MyShader.usf", "MainPS", SF_Pixel);
```

## 4. Permutation 宏

### 4.1 维度定义

| 宏 | 生成的 HLSL 宏 | 取值数 |
|----|---------------|-------|
| `SHADER_PERMUTATION_BOOL(Name)` | `Name = 0/1` | 2 |
| `SHADER_PERMUTATION_INT(Name, Count)` | `Name = 0..Count-1` | Count |
| `SHADER_PERMUTATION_ENUM_CLASS(Name, EnumType)` | `Name = <枚举值>` | 枚举项数 |

> 引擎还提供了取值范围更精细的变体（如 `SHADER_PERMUTATION_RANGE_INT` 等），名称随版本演进，查 `ShaderPermutation.h`。

### 4.2 用法

```cpp
class FMyShader : public FGlobalShader
{
public:
    DECLARE_GLOBAL_SHADER(FMyShader);
    SHADER_USE_PARAMETER_STRUCT(FMyShader, FGlobalShader);

    class FUseHDRDim  : SHADER_PERMUTATION_BOOL("USE_HDR");
    class FQualityDim : SHADER_PERMUTATION_INT("QUALITY", 3);
    using FPermutationDomain = TShaderPermutationDomain<FUseHDRDim, FQualityDim>;
};

// 设置
FMyShader::FPermutationDomain Perm;
Perm.Set<FMyShader::FUseHDRDim>(true);
Perm.Set<FMyShader::FQualityDim>(2);

// 读取（在 ShouldCompilePermutation 里）
if (Perm.Get<FMyShader::FQualityDim>() > 2) return false;

// 查找
TShaderMapRef<FMyShader> Shader(View.ShaderMap, Perm);
```

### 4.3 配套函数

| 函数 | 作用 |
|------|------|
| `ShouldCompilePermutation(Parameters)` | 裁剪：返回 false 则不编译该组合 |
| `ModifyCompilationEnvironment(Parameters, OutEnvironment)` | 追加自定义宏定义 |
| `OutEnvironment.SetDefine(TEXT("NAME"), Value)` | 添加一个 `-D` |

### 4.4 Permutation 参数类型

| 类型 | 额外字段 |
|------|---------|
| `FGlobalShaderPermutationParameters` | `Platform`、`PermutationId` |
| `FMaterialShaderPermutationParameters` | + `MaterialParameters`（BlendMode、ShadingModels...） |
| `FMeshMaterialShaderPermutationParameters` | + `VertexFactoryType` |

## 5. 序列化宏

| 宏 | 作用 |
|----|------|
| `LAYOUT_FIELD(Type, Name)` | 声明参与序列化布局的成员 |
| `Ar << Member` | 在 `Serialize()` 中显式读写 |

```cpp
virtual bool Serialize(FArchive& Ar) override
{
    bool bOutdated = FGlobalShader::Serialize(Ar);
```

## 6. HLSL 端：资源声明宏（跨平台必备）

UE 的 HLSL 会被翻译成 MSL / GLSL，因此**必须用引擎的抽象宏声明资源**，不能写原生 `Texture2D<>`。

### 6.1 纹理

| 宏 | 展开为（HLSL 路径） |
|----|-------------------|
| `TEXTURE2D(Name)` | `Texture2D Name;` |
| `TEXTURE2D_ARRAY(Name)` | `Texture2DArray Name;` |
| `TEXTURE3D(Name)` | `Texture3D Name;` |
| `TEXTURECUBE(Name)` | `TextureCube Name;` |
| `TEXTURECUBEARRAY(Name)` | `TextureCubeArray Name;` |
| `TEXTURE2DARRAYMS(Name)` | `Texture2DArrayMS Name;` |
| `TEXTURE2DMS(Name)` | `Texture2DMS Name;` |
| `RWTEXTURE2D(Name, Type)` | `RWTexture2D<Type> Name;` |
| `RWTEXTURE2DARRAY(Name, Type)` | `RWTexture2DArray<Type> Name;` |
| `RWTEXTURE3D(Name, Type)` | `RWTexture3D<Type> Name;` |

### 6.2 采样器

| 宏 | 展开为 |
|----|-------|
| `SAMPLERSTATE(Name)` | `SamplerState Name;` |
| `SAMPLERCOMPARISONSTATE(Name)` | `SamplerComparisonState Name;` |

### 6.3 缓冲

| 宏 | 展开为 |
|----|-------|
| `STRUCTUREDBUFFER(Name, Type)` | `StructuredBuffer<Type> Name;` |
| `RWSTRUCTUREDBUFFER(Name, Type)` | `RWStructuredBuffer<Type> Name;` |
| `BYTEADDRESSBUFFER(Name)` | `ByteAddressBuffer Name;` |
| `RWBYTEADDRESSBUFFER(Name)` | `RWByteAddressBuffer Name;` |
| `RWBUFFER(Name, Type)` | `RWBuffer<Type> Name;` |

### 6.4 声明示例

```hlsl
// ✅ 跨平台写法
TEXTURE2D(InputTexture);
TEXTURE2D_ARRAY(ArrayTexture);
SAMPLERSTATE(LinearSampler);
RWTEXTURE2D(OutputTexture, float4);
STRUCTUREDBUFFER(LightData, FLightData);
RWSTRUCTUREDBUFFER(OutputData, float4);

// ❌ 不要这样（在 Metal/GL 路径上可能失败或行为不同）
Texture2D<float4> InputTexture;
SamplerState LinearSampler;
RWTexture2D<float4> OutputTexture;
```

## 7. HLSL 端：采样与读写宏

### 7.1 采样（**必须走宏**）

| 宏 | 用途 |
|----|------|
| `Texture2DSample(Tex, Sampler, UV)` | 标准采样 |
| `Texture2DSampleLevel(Tex, Sampler, UV, Lod)` | 指定 mip |
| `Texture2DSampleBias(Tex, Sampler, UV, Bias)` | mip 偏移 |
| `Texture2DSampleGrad(Tex, Sampler, UV, DDX, DDY)` | 显式梯度 |
| `Texture2DSampleArray(Tex, Sampler, UV, ArrayIndex)` | 数组纹理 |
| `Texture2DArraySampleLevel(Tex, Sampler, UV, Idx, Lod)` | 数组纹理 + mip |
| `TextureCubeSample(Tex, Sampler, UV)` | 立方体图 |
| `TextureCubeSampleLevel(Tex, Sampler, UV, Lod)` | 立方体图 + mip |
| `Texture2DSampleCmpLevelZero(Tex, CmpSampler, UV, Value)` | 比较采样（阴影） |
| `TextureLoad(Tex, Coord, Mip)` | 无采样直接读取 |

> **为什么必须走宏**：Metal 与 GLSL 没有"纹理对象与采样器分离"的模型，UE 的宏在那些平台上会展开成"合并采样器"形式。

### 7.2 UAV 读写

```hlsl
RWTEXTURE2D(OutputTexture, float4);

OutputTexture[Pixel] = float4(1, 0, 0, 1);        // 写
float4 V = OutputTexture[Pixel];                   // 读（Texture2D 用 .Load）
```

| 操作 | 写法 |
|------|------|
| 原子加 | `InterlockedAdd(RWValue, 1, OriginalValue);` |
| 原子最小/最大 | `InterlockedMin` / `InterlockedMax` |
| 原子比较存储 | `InterlockedCompareStore` |
| 组内同步 | `GroupMemoryBarrierWithGroupSync();` |
| 设备级同步 | `DeviceMemoryBarrierWithGroupSync();` |
| 全内存屏障 | `AllMemoryBarrier();` |

### 7.3 Compute 语义

| 语义 | 含义 |
|------|------|
| `[numthreads(X, Y, Z)]` | 线程组大小 |
| `SV_DispatchThreadID` | 全局线程 ID |
| `SV_GroupID` | 线程组 ID |
| `SV_GroupThreadID` | 组内线程 ID |
| `SV_GroupIndex` | 组内线性索引 |

## 8. HLSL 端：内置 Uniform Buffer

### 8.1 `View`（`FViewUniformShaderParameters`）

| 成员 | 类型 | 含义 |
|------|------|------|
| `View.ViewToClip` | `float4x4` | 视图 → 裁剪 |
| `View.TranslatedWorldToClip` | `float4x4` | （相对相机）世界 → 裁剪 |
| `View.ViewSizeAndInvSize` | `float4` | (W, H, 1/W, 1/H) |
| `View.WorldCameraOrigin` | `float3` | 相机世界位置 |
| `View.ScreenPositionScaleBias` | `float4` | 屏幕位置缩放偏移 |
| `View.RealTime` / `View.GameTime` | `float` | 时间 |

**辅助函数**：

```hlsl
float2 UV     = SvPositionToBufferUV(SvPosition, View);   // SV_Position → [0,1] UV
float2 SvPos  = BufferUVToSvPosition(UV, View);           // UV → SV_Position
float2 ScrPos = SvPositionToScreenPosition(SvPosition, View);
float3 WorldDir = View.ScreenToTranslatedWorld(...)       // 屏幕 → 世界方向
```

### 8.2 `Primitive`（`FPrimitiveUniformShaderParameters`）

| 成员 | 含义 |
|------|------|
| `Primitive.LocalToWorld` | 局部 → 世界（LWC 下已平移） |
| `Primitive.WorldToLocal` | 世界 → 局部 |
| `Primitive.ObjectWorldPositionAndRadius` | float4（xyz=中心，w=半径） |
| `Primitive.ObjectBounds` | 包围盒尺寸 |

### 8.3 `Material`

材质参数通过 `Material` 全局 UB 传递；在 shader 里通过材质查询函数访问（见 [05 篇 §3.3](05-实战-自定义Mesh与材质Shader.md)）：

```hlsl
float3 BaseColor = GetMaterialBaseColor(PixelMaterialInputs);
float  Roughness = GetMaterialRoughness(PixelMaterialInputs);
```

### 8.4 精度宏

| 宏 | 含义 |
|----|------|
| `MaterialFloat` | 材质精度浮点（按材质设置可为 `half` 或 `float`） |
| `MaterialFloat2` / `3` / `4` | 对应向量 |
| `half` / `half2..4` | 半精度 |
| `float` / `float2..4` | 单精度 |

## 9. HLSL 端：材质编译宏

由 `FMaterialCompilationOutput` 注入，用于条件编译。

| 宏 | 含义 |
|----|------|
| `MATERIAL_TWOSIDED` | 双面 |
| `MATERIAL_MASKED` | 使用 Mask |
| `MATERIAL_TRANSLUCENT` | 半透明 |
| `MATERIAL_BLEND_OPAQUE` / `_MASKED` / `_TRANSLUCENT` / `_ADDITIVE` / `_MODULATE` / `_ALPHAHOLDOUT` | 混合模式 |
| `MATERIAL_SHADINGMODEL_DEFAULT` / `_UNLIT` / `_SUBSURFACE` / `_CLEAR_COAT` / `_CLOTH` / `_EYE` / `_HAIR` 等 | 着色模型 |
| `MATERIAL_USES_SCENE_COLOR_COPY` | 需要场景色拷贝 |
| `USES_WORLD_POSITION_OFFSET` | 用了世界位置偏移 |
| `NUM_MATERIAL_TEXCOORDS` | 材质用到的 UV 套数 |
| `NUM_CUSTOM_VERTEX_INTERPOLATORS` | 自定义插值器数量 |

用法：

```hlsl
#if MATERIAL_TWOSIDED
    // 双面：翻转法线
    Normal *= Input.TwoSidedSign;
#endif

#if NUM_MATERIAL_TEXCOORDS > 1
    float2 UV1 = GetUV(Parameters, 1);
#endif
```

> 完整且权威的列表在 `MaterialShared.cpp` 的 `GetMaterialEnvironment()` 中，版本间会增删。

## 10. HLSL 端：平台与 Feature Level 宏

| 宏 | 含义 |
|----|------|
| `FEATURE_LEVEL_ES3_1` | 移动端 / 低端 |
| `FEATURE_LEVEL_SM4` / `FEATURE_LEVEL_SM5` | D3D11 级 |
| `FEATURE_LEVEL_SM6` | D3D12 Ultimate 级 |
| `COMPILER_HLSL` / `COMPILER_METAL` / `COMPILER_GLSL` | 目标语言（用于极少数必须分流的写法） |
| `USE_DEVELOPMENT_SHADERS` | 开发模式编译 |
| `PLATFORM_SUPPORTS_*` | 平台能力（如是否支持某些扩展） |

用法：

```hlsl
#if FEATURE_LEVEL >= FEATURE_LEVEL_SM6
    float Sum = WaveActiveSum(Value);      // SM6 Wave Ops
#else
    float Sum = ManualSumAcrossGroup();    // 回退
#endif
```

> ⚠️ **平台/编译器宏应尽量少用**。优先依赖 UE 的抽象宏（`TEXTURE2D` / `Texture2DSample` / `MaterialFloat`），只有真正的硬件能力差异（Wave Ops、Bindless）才用 `#if` 分流。

## 11. HLSL 端：常用工具宏与常量

| 宏 / 常量 | 含义 |
|-----------|------|
| `PI` / `PI2` / `INV_PI` | 圆周率相关 |
| `saturate(x)` | 钳制到 [0,1] |
| `lerp(a, b, t)` | 线性插值 |
| `frac(x)` | 小数部分 |
| `Square(x)` | x*x |
| `Pow2(x)` ~ `Pow5(x)` | 快速整数次幂 |
| `CheckerFromPoint` 等噪声函数 | `Common.ush` / `Random.ush` |
| `LWCToFloat()` / `LWCPromote()` | 大世界坐标转换（`/Engine/Private/LargeWorldCoordinates.ush`） |

常用 include：

```hlsl
#include "/Engine/Public/Platform.ush"            // 平台与 FeatureLevel 宏
#include "/Engine/Private/Common.ush"             // View/Primitive UB、数学、采样宏
#include "/Engine/Private/ScreenPass.ush"         // 全屏 Pass 辅助
#include "/Engine/Private/DeferredShadingCommon.ush"  // GBuffer 编解码
#include "/Engine/Private/ShadingCommon.ush"      // Shading Model
#include "/Engine/Private/SceneTexturesCommon.ush"// 场景纹理采样
```

## 12. 宏命名规律（记忆法）

```
SHADER_PARAMETER[_RDG]_[资源种类][_修饰符]
        │           │        │         │
        │           │        │         └─ _SRV / _UAV
        │           │        └─────────── TEXTURE / BUFFER / UNIFORM_BUFFER
        │           └──────────────────── RDG 资源（在 RDG Pass 内使用）
        └─────────────────────────────── 宏族前缀

SHADER_PARAMETER_STRUCT[_INCLUDE | _REF]
                        │         │
                        │         └─ 引用全局 Uniform Buffer
                        └─────────── 内联展开成员到父结构

[DECLARE | IMPLEMENT]_[GLOBAL_]SHADER[_TYPE | _PARAMETER_STRUCT]
    │        │
    │        └─ 全局（不依赖材质）
    └────────── 声明（头文件）/ 实现（cpp，会注册到全局表）

SHADER_PERMUTATION_<维度类型>(HLSL宏名[, 参数])
                                  └─ BOOL / INT / ENUM_CLASS
```

**配对关系速记**：

| BEGIN | END |
|-------|-----|
| `BEGIN_SHADER_PARAMETER_STRUCT` | `END_SHADER_PARAMETER_STRUCT()` |
| `BEGIN_GLOBAL_SHADER_PARAMETER_STRUCT` | `END_GLOBAL_SHADER_PARAMETER_STRUCT()` |
| `DECLARE_*` | `IMPLEMENT_*` |
| `SHADER_USE_PARAMETER_STRUCT` | `BEGIN/END_SHADER_PARAMETER_STRUCT` |

## 13. 版本差异提示

| 项 | 说明 |
|----|------|
| 参数宏 | UE5 持续把非 RDG 的 `SHADER_PARAMETER_TEXTURE` 等往 RDG 版本迁移；新代码优先用 `RDG_*` |
| Permutation | 新增的范围型维度宏名在不同 5.x 版本间有调整 |
| 材质 UB | `FMaterial`/`SceneTextures` 的承载方式（全局 UB ↔ 内联结构体）在 5.x 中改过 |
| RHI 参数 | `SetShaderValue(RHICmdList, ...)` 逐步被 `SetShaderValue(FRHIBatchedShaderParameters&, ...)` 取代 |
| 材质着色器容器 | `FMaterialShaderMap` → `FMaterialShaders`（5.3 起） |

> **最可靠的做法**：在你自己的引擎源码里 `Ctrl+Shift+F` 搜宏名，看当前版本的真实定义与用法示例。

## 14. 小结

| 类别 | 记住这几条就够了 |
|------|-----------------|
| 参数结构体 | `SHADER_PARAMETER` / `_TEXTURE` / `_SAMPLER` / `_RDG_TEXTURE_UAV` / `_STRUCT_REF` / `RENDER_TARGET_BINDING_SLOTS()` |
| 全局 UB | `BEGIN_GLOBAL_SHADER_PARAMETER_STRUCT` + `IMPLEMENT_..._STRUCT(Type, "Name")` |
| Shader 声明 | `DECLARE_GLOBAL_SHADER` / `DECLARE_SHADER_TYPE` + `IMPLEMENT_*` |
| Permutation | `SHADER_PERMUTATION_BOOL/INT/ENUM_CLASS` + `ShouldCompilePermutation` |
| HLSL 资源 | `TEXTURE2D` / `SAMPLERSTATE` / `RWTEXTURE2D` / `STRUCTUREDBUFFER` |
| HLSL 采样 | `Texture2DSample` / `Texture2DSampleLevel` / `TextureCubeSampleLevel` |
| 内置 UB | `View.*` / `Primitive.*` / `Material.*` |
| 材质宏 | `MATERIAL_*`（混合、着色模型、双面、UV 套数） |
