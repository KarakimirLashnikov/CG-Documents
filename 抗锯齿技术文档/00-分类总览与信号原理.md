# 抗锯齿技术 — 分类总览与信号原理

> 本文档是「抗锯齿（AA）技术」系列文档的第 **0** 篇。本篇建立统一分类框架：先讲清抗锯齿的**信号处理本质**，再用「四问」把十余种技术各归其位，最后给出命名规范与混淆速查。

---

## 1. 为什么「抗锯齿」是个伞形词

「开抗锯齿」这句话信息量约等于零。原因在于 **AA 不是一种技术，而是一族技术**，它们：

| 差异维度 | 具体表现 |
|---------|---------|
| **针对的信号来源不同** | 几何边缘、纹理高频、着色高频、时间闪烁、字体边缘、显示子像素 |
| **作用的管线阶段不同** | 几何/光栅、像素/着色、后处理、时间、UI 合成、显示 |
| **采样机制不同** | 提高空间采样率、提高覆盖率精度、时间累积、后处理滤波、预过滤、模型重建 |
| **代价结构完全不同** | 存储 ×N、着色 ×N、带宽 ×N、延迟、伪影（模糊/鬼影/条带） |

把 MSAA 和 mipmap 都叫「抗锯齿」，就像把「退烧药」和「抗生素」都叫「药」——都对，但讨论时毫无帮助。

```
┌──────────────────────────────────────────────────────────────────────────┐
│  一个反直觉的事实                                                          │
│                                                                          │
│  MSAA 和 mipmap 都被称为「抗锯齿」，但它们                               │
│    · 作用的阶段没有交集（光栅化 vs 纹理采样）                              │
│    · 解决的信号源没有交集（几何边界 vs 纹理信号）                          │
│    · 代价结构没有交集（存储/带宽 vs 预过滤/缓存）                          │
│    · 互相不可替代，且必须同时使用                                          │
│                                                                          │
│  → 所以"开了 MSAA 就不用 mipmap"或反之，都是概念错误                       │
└──────────────────────────────────────────────────────────────────────────┘
```

## 2. 第一性原理：抗锯齿到底在解决什么

### 2.1 数学本质

渲染的目标是计算一个**连续函数** \(f(x,y)\)（理想图像），但屏幕只能存储**离散采样**。采样率不足时，高频信息会被错误地重建为低频信号——这就是**混叠（aliasing）**。

```
┌──────────────────────────────────────────────────────────────────────────┐
│  采样与重建的抽象模型                                                     │
│                                                                          │
│   真实场景（连续信号，含无限高频）                                          │
│         │                                                                │
│         │  ① 采样（Sampling）—— 在有限个点上求值                          │
│         ▼                                                                │
│   离散样本集（像素网格）                                                   │
│         │                                                                │
│         │  ② 重建（Reconstruction）—— 从样本恢复连续信号                   │
│         ▼                                                                │
│   显示图像（连续信号）                                                     │
│                                                                          │
│  问题出在两处：                                                           │
│    · 采样阶段：如果信号的高频超过采样率的一半（奈奎斯特频率），              │
│               高频就会"折叠"成错误的低频 → 混叠                            │
│    · 重建阶段：用 box filter（点采样）重建会产生块状边缘                    │
└──────────────────────────────────────────────────────────────────────────┘
```

### 2.2 混叠的两个维度

```
                空间混叠                        时间混叠
        ┌─────────────────────────┐   ┌─────────────────────────┐
        │ 几何边缘的阶梯状锯齿      │   │ 运动时的闪烁（shimmer）  │
        │ 纹理缩小时的摩尔纹        │   │ 亚像素细节的抖动         │
        │ 高光的碎斑              │   │ 细几何（栅栏、树叶）的    │
        │ 法线贴图密集处的噪点      │   │ 时序不稳定              │
        └─────────────────────────┘   └─────────────────────────┘
                    │                              │
                    │   静态画面就能看到            │   必须动起来才明显
                    └──────────────┬───────────────┘
                                   ▼
                        本质是同一件事：
                  采样率不足以表达信号的频率
```

⚠️ **这个区分非常重要**，因为它解释了为什么「MSAA 有效」和「MSAA 不够」可以同时成立：

- MSAA 提高了**几何边缘的空间采样率** → 解决几何边缘混叠 ✅
- MSAA 没有提高**时间采样率** → 运动时的闪烁照旧 ❌
- MSAA 没有提高**纹理空间采样率** → 摩尔纹照旧 ❌
- MSAA 没有提高**着色采样率** → 高光碎斑照旧 ❌

### 2.3 四条解决路径

所有 AA 技术，本质上都是以下四条路径之一（或组合）：

```
┌──────────────────────────────────────────────────────────────────────────┐
│  路径 ①：提高采样率（Increase Sampling Rate）                              │
│    · SSAA    —— 每个子像素完整走一遍管线（着色率也提高）                     │
│    · MSAA    —— 只提高覆盖率/深度/模板的采样率（着色率不变）                 │
│    · CSAA/EQAA —— MSAA 的覆盖率增强变体                                   │
│    · TAA     —— 在**时间维度**上累积采样（每帧用不同的亚像素抖动）           │
│    · 超分重建 —— 从低分辨率样本重建高分辨率（DLSS/FSR/XeSS/ASR）           │
│    特点：真正增加信息量，效果最"物理正确"                                    │
│    代价：存储 / 带宽 / 着色 / 延迟                                          │
├──────────────────────────────────────────────────────────────────────────┤
│  路径 ②：预过滤（Prefiltering）—— 在采样前就抑制高频                      │
│    · Mipmap       —— 按 LOD 选择预平均过的纹理层                           │
│    · 各向异性过滤  —— 沿纹理的压缩方向额外采样                              │
│    · Toksvig / LEAN / CLEAN —— 把法线方差折进粗糙度，抑制高光走样          │
│    · 预积分 BRDF   —— split-sum 近似（Karis 2013）                        │
│    · SDF          —— 用距离场表示解析边缘，天然抗锯齿                       │
│    特点：最便宜，且是**唯一**能根治纹理/着色高频的手段                        │
│    代价：预计算 / 存储 / 精度损失 / 与压缩格式冲突                          │
├──────────────────────────────────────────────────────────────────────────┤
│  路径 ③：后处理重建（Post-Process Reconstruction）                        │
│    · FXAA / SMAA / MLAA / CMAA —— 在最终图像上找边缘再混合                 │
│    特点：极便宜，与管线解耦，可以事后补救                                     │
│    代价：模糊、不增加信息、不解决时间混叠、可能糊掉 UI                        │
├──────────────────────────────────────────────────────────────────────────┤
│  路径 ④：模型/先验重建（Learned Reconstruction）                          │
│    · DLSS 4（Transformer）、FSR 4（ML）、XeSS 2（XMX/DP4a）               │
│    特点：用训练出的先验从稀疏样本推断高频，质量可超过原生                     │
│    代价：硬件依赖 / 模型依赖 / 伪影形态不可预测 / 需要运动矢量                │
└──────────────────────────────────────────────────────────────────────────┘
```

⚠️ **关键洞察**：**路径 ② 是不可省略的**。无论用多贵的 AA，如果不做 mipmap 和法线方差过滤，纹理缩小时的摩尔纹和高光走样都无法根治——因为那些高频信息**在采样时就已经丢失了**，后处理无从恢复。这是很多项目「开了 TAA 还是有噪点」的根因。

## 3. 分类框架：四问法

### 3.1 前两问：来源与阶段

```
                 ┌─────────────────────────────┐
                 │  Q1：锯齿从哪来？             │
                 │   （信号来源）                │
                 └──────────────┬──────────────┘
                                │
        ┌───────────┬───────────┼───────────┬───────────────┐
        ▼           ▼           ▼           ▼               ▼
   ① 几何边缘   ② 纹理/着色  ③ 时间     ④ UI/字体    ⑤ 显示子像素
     0/1覆盖      高频不足     采样抖动    alpha边缘     RGB 排列
        │           │           │           │               │
        └───────────┴───────────┴───────────┴───────────────┘
                                │
                 ┌──────────────▼──────────────┐
                 │  Q2：在哪个阶段处理？         │
                 └──────────────┬──────────────┘
                                │
      ┌─────────┬─────────┬─────┴─────┬─────────┬──────────┐
      ▼         ▼         ▼           ▼         ▼          ▼
   几何/光栅  像素/着色  纹理采样   后处理    时间累积   UI/显示合成
```

### 3.2 后两问：机制与代价

| 问题 | 为什么问 |
|------|---------|
| **Q3：怎么处理？** | 是「提高采样率」还是「预过滤」还是「后处理伪造」？这决定了它能解决哪类混叠 |
| **Q4：代价付在哪里？** ⭐ | 存储 ×N？着色 ×N？带宽 ×N？延迟？伪影？—— 这一问决定它在你的预算里能不能用 |

**Q4 是实践中最重要的一问**，也是原分类框架里最容易忽略的一问。同一个「抗锯齿」标签下，代价可以差几十倍：

| 技术 | 主导代价 | 量级感觉 |
|------|---------|---------|
| Mipmap | 显存 +33% / 缓存 | 几乎免费 |
| 各向异性过滤 4x | 纹理带宽 ×2~4 | 便宜 |
| FXAA | 1 个 pass + 1 张全屏 RT | 便宜 |
| SMAA | 2~3 个 pass | 便宜 |
| MSAA 4x（桌面 IMR） | 深度/颜色存储 ×4 + resolve 带宽 | 中等 |
| MSAA 4x（移动 TBDR） | 片上内存 ×4（**resolve 在片上，不额外走总线**） | 移动端反而相对便宜 |
| TAA | 1 张历史帧 + 1 张运动矢量 RT + 每帧全屏 pass | 中等 |
| SSAA 4x | 着色 ×4 + 存储 ×4 + 带宽 ×4 | 昂贵 |
| DLSS/FSR/XeSS | 硬件要求 + 延迟 + 伪影 | 视平台 |

⚠️ **最后一行「MSAA 在移动端更便宜」不是笔误**。TBDR 架构的 MSAA resolve 在片上完成，带宽代价远低于桌面 IMR。这是移动端 Forward 管线可以放心用 2x MSAA 的原因（Adreno 官方称 MSAAx2 实践中通常近乎免费），详见本系列第 4 篇。

## 5. 最容易混淆的八个点

### 5.1 MSAA ≠ 几何抗锯齿的全部

**更准确的叫法**：**几何边缘覆盖率抗锯齿**（Geometry Edge Coverage AA）。

它做的事：为每个像素维护 N 个**覆盖率/深度/模板样本**，几何边界按覆盖率混合；但**片元着色通常在像素中心执行一次**，纹理采样也是每像素一次。

⚠️ 精确表述：MSAA 的「多采样颜色」是硬件在 resolve 时按覆盖率与权重生成的，**不是 shader 逐样本算的**。这正是它能在几何边缘达到接近 SSAA 的效果、却远便宜于 SSAA 的原因。

**能解决**：几何边缘（三角形边界）。
**不能解决**：纹理内部边缘、高光走样、法线贴图高频、时间闪烁、UI 纹理边缘。

### 5.2 SSAA 才是「全管线超采样」

SSAA 让**每个子像素完整走一遍着色**。因此它同时解决几何边缘、着色边缘、纹理边缘——但也意味着着色、存储、带宽全部 ×N。

| 维度 | MSAA | SSAA |
|------|------|------|
| 着色频率 | 每像素一次 | 每子像素一次 |
| 深度/模板采样 | ×N | ×N |
| 颜色采样 | ×N（硬件生成） | ×N（真实着色结果） |
| 解决几何边缘 | ✅ | ✅ |
| 解决纹理/着色高频 | ❌ | ✅ |
| 相对成本 | 低 | 高（全管线 ×N） |

常见的 SSAA 变体（多为 NVIDIA 驱动侧，需 Profile Inspector 配置）：

| 变体 | 说明 |
|------|------|
| **OGSSAA** | Ordered Grid SSAA，规则网格，模式有 2x1 / 1x2 / 2x2 / 3x3 / 4x4 |
| **SGSSAA** | Sparse Grid SSAA，稀疏网格，质量更高、代价极大 |
| **TrSSAA** | Transparency SGSSAA，只对透明物体做稀疏网格超采样（用于 alpha test 植被） |
| **HSAA** | Hybrid Sampling AA，SSAA + MSAA 混合 |
| **RGSS** | Rotated Grid SSAA，旋转网格（经典 4x RGSS） |

### 5.3 后处理 AA 不是「采样」，是「修图」

FXAA / SMAA 在**最终图像**上找边缘再混合。它们不增加采样，只是在已混叠的图像上做形态学修正。

| 后果 | 说明 |
|------|------|
| ✅ 极便宜 | 1~3 个 pass，与场景复杂度无关 |
| ✅ 通用 | 能处理 MSAA 解决不了的着色/纹理边缘（因为那些已经混叠在图像里了） |
| ❌ 会模糊 | 抑制了边缘对比度，文本/UI 尤其明显 |
| ❌ 不解决时间闪烁 | 每帧独立修图，帧间的抖动照旧 |
| ❌ 不增加真实信息 | 是猜，不是测 |

⚠️ **必须在 HUD 之前应用**，否则会把 UI/字体糊掉。这是实现层的硬性顺序要求。

### 5.4 TAA 不是简单后处理

TAA 是**时间采样**：每帧用不同的亚像素抖动（jitter）偏移投影矩阵，靠历史帧累积把采样点"弥散"到亚像素网格上。

| 组件 | 作用 |
|------|------|
| **Jitter** | 每帧偏移投影矩阵（如 Halton 序列），使采样点遍历像素内的不同位置 |
| **Motion Vector** | 把历史帧样本重投影到当前帧坐标，必须精确（否则鬼影） |
| **History Buffer** | 累积的历史颜色（需要额外一张全分辨率 RT） |
| **Neighborhood Clamping** | 用当前帧邻域限制历史样本的取值，抑制鬼影 |
| **Variance Clipping** | 邻域截断的统计学改进版，效果更好 |
| **YCoCg 空间混合** | 在亮度-色度空间做混合，减少色度渗漏 |
| **Catmull-Rom 重采样** | 历史样本的双线性/双三次重采样，减轻模糊 |

**能解决**：几何 + 着色 + 纹理 + 时间的混叠（覆盖面最广）。
**代价**：鬼影（ghosting）、模糊、拖尾、高频细节的时序不稳定、需要运动矢量。

### 5.5 纹理过滤不是屏幕空间 AA

Mipmap / 各向异性解决的是**纹理空间**的采样问题：纹理缩小时（一个像素覆盖多个纹素）需要预过滤。

**它不解决三角形边缘**（那是屏幕空间的几何问题）。

⚠️ **反向也成立**：MSAA 不解决纹理摩尔纹。两者必须配合，且**没有替代关系**。

### 5.6 字体 / UI AA 是另一条线

字体灰度 AA、LCD 子像素、SDF/MSDF、预乘 alpha 都是 UI 专用。

⚠️ **关键实践点**：它们通常**在后处理之后单独合成**，不参与场景 AA。这样做的原因：

```
┌──────────────────────────────────────────────────────────────────────────┐
│  如果 UI 参与场景 AA 会发生什么                                            │
│                                                                          │
│  · UI 被 TAA 的历史累积污染 → 拖动 UI 时出现鬼影                            │
│  · UI 被 FXAA/SMAA 的边缘检测处理 → 文本变糊                               │
│  · UI 在低分辨率下渲染再被超分 → 字体笔画丢失                               │
│  · UI 被 VRS 降采样 → 文本严重退化                                        │
│                                                                          │
│  → 正确做法：UI 在最终分辨率、后处理之后、以原生像素为单位单独合成            │
└──────────────────────────────────────────────────────────────────────────┘
```

### 5.7 Alpha-to-Coverage 是把「纹理边缘」伪装成「几何边缘」

A2C 把 shader 输出的 alpha 转换为 MSAA 的 coverage mask。它让 MSAA 能处理 alpha 边缘（如植被、栅栏），并得到**正确的深度写入**（解决 alpha test 的排序问题）。

⚠️ **但有两个硬限制**：

1. **质量受 MSAA 采样数限制**：4x MSAA 只有 4 级覆盖率 → 会出现明显条带
2. **在移动端会破坏隐面剔除**：A2C 相当于修改 coverage mask，ARM 官方把它归入 `Modifies coverage` 检查项 → 强制 late ZS update，降低 early ZS 与 HSR 效率

### 5.8 「AA 与超分」正在合并

现代趋势是把三件事合成一步，这是理解当前 AA 格局的关键：

```
┌──────────────────────────────────────────────────────────────────────────┐
│  传统模型：低采样 → 抗锯齿 → 输出原生分辨率                                │
│                                                                          │
│  现代模型：低分辨率渲染 + 抖动 → 用先验重建到高分辨率（同时完成 AA）          │
│                                                                          │
│  · 抗锯齿（AA）                                                           │
│  · 上采样（Upscaling）                                                    │
│  · 时间重建（Temporal Reconstruction）                                    │
│      └── 三者合称"超分"，由同一个模型完成                                   │
│                                                                          │
│  代表：DLSS 4 / FSR 4 / XeSS 2 / Arm ASR / MetalFX / Qualcomm GSR       │
└──────────────────────────────────────────────────────────────────────────┘
```

所以「AA 和超分是两个独立功能」这个心智模型已经过时了。

## 6. 命名规范：以后怎么说

不要只说「开抗锯齿」。建议按 **来源 + 机制** 命名：

| 规范说法 | 涵盖技术 | 一句话定位 |
|---------|---------|-----------|
| **几何边缘 AA** | MSAA、CSAA/EQAA、解析 AA | 提高几何边界的覆盖率精度 |
| **全管线超采样 AA** | SSAA（OGSSAA/SGSSAA/RGSS）、HSAA | 每个子像素完整着色 |
| **图像空间后处理 AA** | FXAA、SMAA、MLAA、CMAA | 在图像上找边缘再混合 |
| **时间 AA** | TAA、TAAU | 帧间抖动累积 |
| **时间重建 / 超分** | DLSS、FSR、XeSS、ASR、MetalFX、GSR | 低分辨率渲染 + 模型重建 |
| **纹理过滤 AA** | Mipmap、各向异性过滤 | 纹理层预过滤 |
| **材质/高光 AA** | Toksvig、LEAN、CLEAN、预积分 BRDF | 把法线方差折进粗糙度 |
| **UI / 字体 AA** | 灰度 AA、LCD 子像素、SDF/MSDF、预乘 alpha | UI 合成层专用 |
| **覆盖率 AA** | Alpha-to-Coverage、解析覆盖 | 用覆盖率表达边缘 |

**一句话记忆**：

> MSAA 是**几何边缘覆盖率 AA**；SSAA 是**全管线超采样**；FXAA/SMAA 是**图像空间后处理**；TAA 是**时间采样**；DLSS/FSR/XeSS 是**时间重建/超分**；Mipmap/Aniso 是**纹理过滤**；Toksvig/LEAN 是**材质高光 AA**；SDF/字体 AA 是 **UI 专用**。

## 7. 术语表

| 术语 | 全称 | 准确含义 | 常见误用 |
|------|------|---------|---------|
| AA | Anti-Aliasing | 抗混叠。伞形词，必须限定来源与阶段 | 误当作单一技术 |
| MSAA | Multi-Sample AA | 多样本：深度/模板/覆盖率 ×N，着色每像素一次 | 误以为着色也 ×N |
| SSAA / FSAA | Super-Sample / Full-Screen AA | 全管线超采样，每个子像素完整着色 | 与 MSAA 混为一谈 |
| CSAA / EQAA | Coverage / Enhanced Quality AA | 在 MSAA 之上加覆盖率样本（不存颜色/深度） | 以为它比高倍 MSAA 全面更好 |
| MFAA | Multi-Frame AA | NVIDIA，MSAA 的时序抖动变体，CSAA 的后继 | — |
| A2C | Alpha-to-Coverage | 把 alpha 转成 MSAA 覆盖率 | 以为它等于 alpha 混合 |
| FXAA | Fast Approximate AA | 单 pass 图像空间 AA，需算 luma | 以为它是"真 AA" |
| SMAA | Subpixel Morphological AA | 形态学 + 模式识别，可带预计算搜索纹理 | — |
| MLAA / CMAA | Morphological / Conservative Morphological AA | AMD / Intel 的形态学 AA | — |
| TAA | Temporal AA | 帧间抖动 + 历史累积 | 误当作后处理滤镜 |
| TAAU | TAA Upsampling | TAA + 从低分辨率重建到高分辨率 | — |
| DLAA | Deep Learning AA | 原生分辨率下的 AI AA（不做超分） | 与 DLSS 混淆 |
| NDF | Normal Distribution Function | 法线分布函数（如 GGX / Beckmann） | — |
| Resolve | — | 把多样本/片上结果合并成最终像素 | 以为只有 MSAA 才有 |
| VRS | Variable Rate Shading | 可变着色率。**降低**着色采样率，与 AA 目标相反 | 误当作 AA 技术 |

## 9. 小结

| 要点 | 说明 |
|------|------|
| **AA 是一族技术，不是一种** | 按「信号来源 × 处理阶段 × 采样机制 × 代价结构」四维区分 |
| **本质是采样与重建问题** | 所有 AA 都可归入四条路径：提高采样率、预过滤、后处理重建、模型重建 |
| **混叠分空间与时间两类** | 这解释了为什么「MSAA 有效」和「MSAA 不够」同时成立 |
| **路径 ②（预过滤）不可省略** | 纹理高频信息在采样时已丢失，后处理无从恢复。这是「开了 TAA 还有噪点」的根因 |
| **MSAA = 几何边缘覆盖率 AA** | 只提高覆盖率/深度/模板采样率，片元着色通常每像素一次 |
| **后处理 AA 是「修图」不是「采样」** | 便宜但会模糊、不解决时间混叠、不增加信息，且必须在 HUD 之前应用 |
| **TAA 是时间采样** | 抖动 + 运动矢量 + 历史累积，覆盖面最广，代价是鬼影与模糊 |
| **纹理过滤与几何 AA 无替代关系** | Mipmap 不管三角形边缘，MSAA 不管纹理摩尔纹，必须同时使用 |
| **UI AA 是独立的一条线** | 必须在后处理之后以原生分辨率合成，否则会被糊掉或被鬼影污染 |
| **AA 与超分已经合并** | 现代方案（DLSS/FSR/XeSS/ASR）同时完成 AA、上采样、时间重建 |
| **代价按 Q4 评估** | 同样叫「抗锯齿」，代价可以差几十倍。移动端 MSAA 反而相对便宜（片上 resolve） |
