资深引擎开发成长路线

一份可执行的 12 个月学习-实践-产出计划，目标岗位为资深引擎/渲染开发程序员。四阶段推进：管线与 RHI → Shader 与光照材质 → 性能优化方法论 → 前沿技术专题，以 UE Vulkan RHI 新特性落地收尾。

6 篇 UE 5.8.2 RDG · RHI · Vulkan Shader 变体治理 Unreal Insights · Nsight Nanite · Lumen · VSM · VT

阶段一（M1–M3）

先建地图再下钻：主线 → RDG 实操 → Vulkan RHI 链路。

01 PIPELINE · RHI

UE渲染管线与RHI定制

  • M1：三时间尺度 + Pass 序列 + 三线程模型，自绘主线全图
  • M2：自定义 RDG Pass 插件（ISceneViewExtension，零引擎侵入）
  • M3：一次 Draw 从 RDG 到 vkCmdDraw* 的默写级链路
  • VulkanRHI 微定制三选一：时间戳注入 / 扩展接入 / PSO 统计
  • 坑：资源依赖漏声明 → 偶发花屏；改 RHI 必须标 CUSTOM
  • 每个概念与 RenderToy FrameGraph 双线对照

阶段二（M4–M6）

从会写 Shader 到能治理数千个变体，再到光照方案选型。

02 SHADER · LIGHTING

Shader体系与光照材质

  • M4：材质 → HLSL → ShaderMap → PSO 全链路 + 自定义 Shader 类型
  • M5：变体治理三段式——统计基线 → 裁剪 → PSO 预热
  • M5：参数三级绑定机制 × SPIRV-Reflect 双向核对工具
  • M6：Lumen / GPU Lightmass / MegaLights 同场景对比 + 选型决策树
  • 坑：公共 ush 改动触发全量重编；裁剪条件引用运行时状态 → PSO miss
  • Substrate 分层材质 + 材质性能审计清单

阶段三（M7–M9）

从会用工具到有方法论闭环：预算分解 → 假设 → 验证 → 固化。

03 PROFILING

性能分析与优化方法论

  • 优化闭环五步：预算分解 → 假设 → 最小验证 → 修复回归 → 防回退
  • M7：Unreal Insights 全工作流 + 三线程时序读图
  • M8：真实场景优化闭环，报告含失败假设
  • M9：Nsight 指标反推法 ≥2 案例 + 移动端差异清单
  • 反模式：编辑器测性能 / 用 % 汇报 / 只看均值 / 一次大改
  • 性能预算表 + 每周自动回归 + PR 数字门禁

阶段四（M10–M12）

前沿专题按统一模板精读，以 Capstone 综合收束全年。

04 FRONTIER · CAPSTONE

前沿渲染技术专题研读与Capstone

  • 六段式专题模板：问题 → 思想 → 细节 → UE 落地 → 量化 → 评估
  • M10：Nanite（cluster / 软件光栅 / VisBuffer / 流送）+ VSM
  • M11：Lumen 数据流 + 虚拟纹理反馈回路 + 纹理映射三选三
  • GDC/SIGGRAPH 精读清单（FrameGraph / Nanite / ReSTIR / MegaLights）
  • M12：Capstone：UE Vulkan RHI 新特性，四候选题 + 报告骨架
  • 验收：能就任一专题做 30 分钟分享并答出「代价是什么」

铁律

全年三条铁律

  • 输入必产出：超 30 分钟的阅读必须留笔记，否则视为没读
  • 实验必量化：「感觉变快」必须配 RenderDoc/Insights 数字
  • 代码必可跑：每个成果可编译运行 + 附复现步骤
  • 汇报用 ms 不用 %；看 P95 不看均值
  • 先 bound 分类再选工具；一次只改一个变量
反模式

六个高频翻车点

  • 源码阅读陷入细节黑洞 → 退回地图式阅读纪律
  • RenderToy 沉迷开新功能 → 只做对照性小实验
  • RDG 资源依赖漏声明 → 偶发花屏，极难排查
  • 改公共 ush → 全量重编数千 Shader
  • 编辑器里测性能 → 数据被编辑器开销淹没
  • 改引擎源码不标 CUSTOM → 版本升级合并灾难
